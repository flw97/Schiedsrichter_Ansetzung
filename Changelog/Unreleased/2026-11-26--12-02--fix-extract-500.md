# Fixed
- The archive deploy returned HTTP 500 and left the API in maintenance mode. Prune calls `rmdir` on directories that still contain the new files; PHP warns "Directory not empty", and the extractor turned that warning into a failed request before `artisan up` could run.
- `lftp get -o` is rejected (`get: invalid option -- 'o'`). The local path has to follow the remote name, so the stamp download never ran and every deploy uploaded both archives.
- A non-200 response from the probe, the extract, or the migrate hook is printed in the job log. The one-off token stays out of that line.
